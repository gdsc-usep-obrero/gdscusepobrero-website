# GDSC USeP Obrero Website

Welcome to the official website of the Google Developer Student Clubs USeP Obrero Chapter. This platform serves as a hub for our community, showcasing events, projects, and resources for students interested in technology and development.

## Technologies Used

- **Next.js**: A React framework for building server-side rendered applications.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **Material-Tailwind**: A set of Tailwind CSS components based on Material Design.

## Deployment

The website is deployed on Vercel and can be accessed at [gdscusep.com](https://gdscusep.com).

## Getting Started

To run the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/gdsc-usep-obrero.git
   cd gdsc-usep-obrero
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and go to** `http://localhost:3000`.
